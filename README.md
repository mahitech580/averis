# Averis by Mahi — Nexus Care OS

Averis Nexus is a fresh, standalone rebuild: a browser-first healthcare operations workspace designed as a single static application for GitHub Pages.

## What it is

Averis is a **simulation-grade care operations OS**, not a real hospital system and not connected to production clinical records. It uses deterministic demo data stored locally in the browser.

Core surfaces include:

- Operations command center
- Live patient flow and triage
- Patient 360
- Care pathways
- Appointments and capacity
- Providers and skills
- Bed / resource orchestration
- Labs and pharmacy
- Billing and revenue signals
- Messages and work queue
- Incident command
- Analytics
- AI copilot simulation
- Audit / system health
- Workspace settings

## Design

No framework, no backend, no build step and no external dependency is required.

- HTML: app shell and accessible semantic structure
- CSS: responsive visual system, dark/light themes, charts, command surfaces
- JavaScript: local state, routing, interactions, demo workflows
- SVG: local visual identity and zero-network decorative background

## Run

Open \`index.html\` directly, or publish the repository with GitHub Pages.

The application is intentionally static. New records, filters, theme preference and workspace state are kept in browser storage.

## Data

All displayed clinical/operational records are synthetic. Never enter real patient information.
