# AVERIS by Mahi

**SIMULATED / LOCAL**

AVERIS is an advanced static portfolio simulation for healthcare coordination and operational intelligence using synthetic data only.

## Workspaces
Today, People, Journeys, Queue, Schedule, Capacity, Workforce, Diagnostics, Pharmacy, Finance, Messages, Incidents, Quality, Insights, Assistant, Reports, Audit and Settings.

## Boundary
No real patient connections. No diagnosis. No treatment recommendations. No clinical decisioning. No external AI API.

## Architecture
HTML/CSS/JS frontend with localStorage persistence, browser-local workflows, command search, dialogs, drawers, exports and audit. Python generates deterministic synthetic JSON/CSV/SQLite data. SQL defines relational entities, foreign keys, check constraints, indexes, views and triggers.
