Run the central API first (`uvicorn backend.main:app --reload --port 8000`) and set `AVERIS_API_URL=http://127.0.0.1:8000/api`. Flask: `python frameworks/flask_portal.py` (port 5001). Django: `py frameworks/django_portal/manage.py runserver 127.0.0.1:8001`. Streamlit: `streamlit run frameworks/streamlit_analytics.py`. Install `requirements-frameworks.txt`. TensorFlow is optional via `requirements-ai.txt` and operates only on generated sample data. These companion apps call the same FastAPI API; use synthetic records only.
