# AVERIS API\n\nFastAPI backend for shared, multi-user AVERIS workspaces.\n\n## Local run\n\n1. Create a virtual environment.\n2. Install `backend/requirements.txt`.\n3. Set `DATABASE_URL=sqlite:///./averis.db` and `APP_ENV=development`.\n4. Run `uvicorn backend.main:app --reload --port 8000`.\n\nOpen `/api/health` and `/api/docs` on `http://127.0.0.1:8000`.\n\nSQLite is used locally by default. SQLAlchemy also supports MySQL (`mysql+pymysql://...`) and PostgreSQL (`postgresql+psycopg://...`). Set connection strings in environment variables; never commit database credentials.\n\nThe API uses Argon2 password hashes, server-side sessions, HttpOnly cookies, Origin checks, tenant-scoped membership, versioned JSON snapshots and server audit events. It is a demo for synthetic data, not a clinical system or a security/compliance certification.\n
